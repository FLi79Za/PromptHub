# Lyrics Structuring Reference

Use this resource when the input includes lyrics or asks for a lyric structure. Preserve wording by default. Repair layout before rewriting meaning.

- Use clear labels such as `[Intro]`, `[Verse]`, `[Pre-Chorus]`, `[Chorus]`, `[Bridge]`, `[Interlude]` and `[Outro]`.
- Keep section labels short and avoid packing narrative commentary into brackets.
- Repeat chorus text when hook consistency is requested; vary verses only when requested.
- Keep line density compatible with the intended delivery. Slow material benefits from shorter lines and breathing room; fast material needs controlled rhythmic units and cadence.
- Performance cues should describe musical behaviour—restrained, wider, denser, sparse, behind the beat—not exact timing commands.
- For instrumental requests, return style and optional arrangement/performance direction, never invented lyrics.

These are practical formatting and prompting conventions. Suno has not published a complete deterministic metatag grammar, so do not promise exact parser behaviour.
